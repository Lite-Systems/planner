# المخطط الذكي — حزمة التحضير للنشر على بيكاليكا

حزمة التحضير لعرض **Smart Planner (المخطط الذكي)** للبيع على متجر بيكاليكا. الحالة العامة: **مسودة مرشّحة (draft-candidate)** — لم تُرسل بعد للمراجعة، وتنقصها عناصر مطلوبة قبل الإرسال.

## السعر المعتمد

- **السعر العام:** 50 دولارًا (اختيار المستخدم، 2026-10-18).
- **التفسير:** سعر ظاهر للمشتري قبل الضرائب، محمّل على **رخصة الاستخدام الشخصية**. يقع داخل نطاق أسعار بيكاليكا رسميًا لفئة التطبيقات (10–100 دولار).
- **التصنيف التجاري (رخصة الاستخدام التجارية):** غير محدد. **مقترح قابل للمراجعة: 120 دولارًا** (داخل النطاق التجاري 10–250). المقترح لا يُعد قرارًا حتى اعتماده.
- **الحصرية:** منتج غير حصري، بعمولة بيكاليكا الرسمية 20% — التفاصيل في `pricing-licenses.md`.

## خطوات التفعيل التالية

1. عالج أولويات `upload-checklist.md` القصوى: استبعاد خط Arial الممنوع، وعناصر حساب البائع، والتقاط غلاف 1700×970.
2. اعتمد سعر الرخصة التجارية الثانية ونوع الحصرية.
3. ابنِ حزمة ZIP المصدرية بقائمة استثناءات واضحة (الخطوط والتهيئة) بعد الملاءمة.
4. أضف تأكيدات النموذج (حدود الحقول، أقل عدد صور) عند توفر مركز مساعدة بيكاليكا.
