# نصوص صفحة العرض (بيكاليكا) — مسودة للنسخ إلى نموذج الرفع

اللغة الأساسية: العربية. الأقسام أدناه تطابق أقسام نموذج رفع المنتج كما وردت في مقتطف مركز المساعدة (العنوان، التصنيف، رابط المعاينة، تفاصيل المنتج، بيانات العرض). حدود طول الحقول غير مؤكدة وتحتاج مراجعة داخل النموذج.

## 1) عنوان المنتج

- **المقترح:** `المخطط الذكي - إدارة المشاريع والمهام والمالية`
- **بديل:** `المخطط الذكي - إدارة مشاريعك ووقتك ومالك`

النمط مأخوذ من إرشادات البائعين: اسم المنتج ثم وصف واضح ومختصر دون عبارات ترويجية (فحص 2026-10-18).

## 2) التصنيف

- **المقترح:** «تطبيقات». التطبيق في الأساس تطبيق جوال (Android / iOS)، وبه إصدارات ويب وسطح مكتب. راجع الخيارات المتاحة داخل النموذج واختر الأنسب.
- تنبيه قواعد المنصة: كون التطبيق مبنيًا بـ Flutter لا يعني اعتباره منتج جوال إذا كان العرض الفعلي لسطح المكتب فقط؛ هنا العرض الأساسي جوال فالتصنيف ملائم.

## 3) رابط المعاينة

- غير متوفر حاليًا. رابط المعاينة المباشر موصى به بقوة في إرشادات بيكاليكا.
- خيار قابل للتنفيذ لاحقًا: صفحة ويب ثابتة أو نسخة `flutter build web` مستضافة تطابق ما سيحصل عليه المشتري.

## 4) وصف المنتج (نص التفاصيل)

```text
المخطط الذكي (Smart Planner) تطبيق مكتمل لإدارة عملك المستقل من مكان واحد:
مشاريع ومهام، تتبّع وقت، إيرادات ومصروفات، محافظ تُحسب أرصدتها تلقائيًا،
وفواتير PDF جاهزة للطباعة والمشاركة — يعمل دون إنترنت وبياناتك في جهازك.

يُسلَّم كشيفرة مصدرية نظيفة (Flutter) قابلة للتعديل والبناء على أندرويد وiOS
والويب وسطح المكتب، مع دليل عربي كامل ودعم RTL أصيل.

أهم القدرات:
- مشاريع لأعضاء وبطاقات غلاف ومدفوعات، وفاتورة PDF لكل مشروع.
- مهام بأنواع وحالات ومهام فرعية ومرفقات وتذكير تلقائي بموعد المهمة.
- مؤقت مدمج لتتبع الوقت وتكلفة الساعة، يحسب التكلفة تلقائيًا من الوقت الفعلي.
- إضافة المهام بالصوت مع تحليل عربي/إنجليزي للمهام الفرعية والفواصل.
- إيرادات تُسجَّل تلقائيًا من المهام المدفوعة، أو تسجيل يدوي مع فئات قابلة للتعديل.
- مصروفات برسم بياني دائري وفئات وتصفية بالشهر والفئة.
- محافظ (نقدية / فيزا / بنك) بأرصدة حية تتغير مع الدخل والمصروف.
- عملات: جنيه / دولار / ريال، مع أسعار صرف محدّثة وتحويل تلقائي بين العملات.
- قفل التطبيق ببصمة أو Face ID أو رمز القفل، وإخفاء المبالغ بوضع الخصوصية.
- نسخ احتياطي واستعادة كامل قاعدة البيانات من وإلى ملف خارجي.
- عربية وإنجليزية (العربية الأساسية) مع وضع داكن ودعم RTL كامل.
- واجهة سطح مكتب بشريط جانبي واختصارات لوحة مفاتيح (Ctrl/Cmd + 1..5).

التقنية: Flutter / Dart 3.12، قاعدة بيانات SQLite محلية، مكتبات PDF للفواتير،
تدويل بـ easy_localization، تذكيرات محلية، وقفل حيوي بـ local_auth.
```

## 5) أقسام صفحة العرض المقترحة (وحدات النموذج)

- **نص و/أو قائمة:** «ماذا ستجد في الحزمة؟»: شيفرة Flutter الكاملة للإصدار 1.0.0+8، دليل مشترِ عربي بصيغة HTML، توثيق التبعيات، وملاحظات التراخيص.
- **نص و/أو قائمة:** «ملاحظات تشغيل مهمة»: يلزم تثبيت Flutter SDK (الدليل يشرح كل خطوة)، والتطبيق لا يعتمد أي خدمة خارجية، وإشعاراته محلية.
- **صور:** لقطات شاشة حقيقية من التطبيق (انظر `presentation-assets.md`).
- **فيديو:** مقطع قصير يعرض الشاشة الرئيسية وإضافة مهمة بالصوت وطباعة فاتورة (موصى به في إرشادات النجاح).

## 6) الوسوم

`flutter` · `إدارة مشاريع` · `مهام` · `مالية` · `فواتير PDF` · `عربي` · `SQLite`

## 7) نواقص قبل النسخ للنموذج

1. تأكيد حدود المحارف داخل نموذج الرفع (غير موثّقة في الصفحات العامة المتاحة).
2. توفير رابط معاينة مباشر.
3. مراجعة التنسيق النهائي مباشرة داخل محرر النموذج بعد النسخ.
