# ملاحظات الإصدار — المخطط الذكي (Smart Planner)

## 1.0.0+8 — مرشّح النشر على بيكاليكا (2026-10-18)

المصدر: `pubspec.yaml` (الحزمة `planner`). ملاحظة: ملف `README.md` الجذري يذكر إصدارًا أقدم (1.0.0+6) ويُعدّل قبل التسليم.

### الميزات المضمّنة

- لوحة رئيسية: بطاقات مالية (مُحصّل، معلّق، صافي)، تقدم المهام، مؤقتات نشطة، وأحدث السجلات.
- مشاريع: أعضاء فريق، غلاف صورة أو رمز، حالات، إجماليات التكلفة والمدفوع والمتبقي.
- مهام: نوع وحالة وتواريخ وتكلفة، مهام فرعية، مرفقات صور وملفات، تذكير بموعد المهمة.
- مهام مدفوعة: دفعة المهمة تُنشئ سجل إيراد تلقائيًا، وإلغاء الدفع يزيله.
- مؤقت تتبع وقت: تشغيل وإيقاف، حساب التكلفة من الوقت وسعر الساعة.
- إضافة المهام بالصوت: تحليل عربي/إنجليزي للمهام الفرعية، مع معاينة قابلة للتعديل قبل الحفظ.
- إيرادات ومصروفات: فئات قابلة للتعديل، تصفية بالشهر والفئة، رسم بياني دائري للمصروفات.
- محافظ: نقدية/فيزا/بنك، رصيد حي = رصيد ابتدائي + دخل − مصروف، وحماية من حذف ما هو مستعمل.
- عملات: جنيه/دولار/ريال، أسعار صرف محدّثة من `open.er-api.com`، تحويل تلقائي.
- فواتير PDF: RTL/LTR، خط عربي مدمج، محتوى قابل للاختيار، طباعة ومشاركة وحفظ ومعاينة.
- تدويل: العربية أساسية والإنجليزية كاملة، مع وضع داكن.
- الحماية: قفل بصمة/Face ID/رمز، إخفاء المبالغ، وقفل تلقائي عند مغادرة التطبيق.
- الإشعارات: محلية فقط (بتاريخ 2026-10-18 أُزيلت إشعارات Firebase/FCM بأمر المالك).
- البيانات: SQLite محلية (v21) مع ترحيل تلقائي من قاعدة قديمة، ونسخ احتياطي واستعادة كامل.
- سطح المكتب: تخطيط عريض، شريط جانبي مضغوط اختياري، اختصارات لوحة مفاتيح.
