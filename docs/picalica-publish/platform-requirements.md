# متطلبات المنصة والمصادر الموثّقة — فحص 2026-10-18

## متطلبات بيكاليكا المؤكدة

المصادر: إرشادات البائعين، صفحة الرخص، والأسئلة الشائعة على بيكاليكا. مركز المساعدة لم يُفتح مباشرة أثناء هذا الفحص، لذلك تبقى تفاصيل نموذج الرفع الدقيقة غير مؤكدة حتى الآن.

| المتطلب | النص الرسمي | حالة منتجنا |
|---|---|---|
| عربية أساسية | محتوى عربي واتجاه عربي مع إمكانية تعدد اللغات | العربية لغة أساسية مع دعم RTL كامل |
| توثيق مع الملفات | ملف كتابي أو فيديو أو HTML يشرح الاستخدام والتعديل | دليل عربي بصيغة HTML جاهز |
| العناصر الخارجية | مجانية ومسموح استخدامها تجاريًا مع ذكر مصدرها | خط Almarai برخصة OFL مسموح توزيعه، وخط Arial ممنوع يُستبعد |
| لا كود تفعيل | المنتجات التي تحتاج كود تفعيل غير مناسبة | لا توجد آلية تفعيل ولا تشفير في الشيفرة |
| قابل للتعديل | شرط أساسي للقبول | شيفرة Flutter كاملة مع دليل تخصيص |
| السعر داخل النطاق | تطبيقات: شخصي 10–100، تجاري 10–250 | الشخصية 50 داخل النطاق، والتجارية 120 مقترح |
| رابط معاينة | موصى به بقوة | غير متوفر حتى الآن (عائق) |
| صور معرض | صور متنوعة عالية الجودة، الرئيسية 1700×970 | مطلوب لقطات شاشة حقيقية (عائق) |
| العنوان | اسم المنتج ثم وصف من 3 إلى 5 كلمات | مقترح: المخطط الذكي - إدارة المشاريع والمهام والمالية |
| الموافقة على الشروط | خطوة داخل نموذج الرفع مع تأكيد إنجاز المنتج بنفسك | تُنفَّذ عند الرفع بعد جاهزية حساب البائع |

## قواعد الدعم المعتمدة

من الأسئلة الشائعة: يستطيع المشتري التواصل مع البائع طلب مساعدة خلال أسبوع من شراء المنتج. وإذا ثبت وجود مشكلة في المنتج أو تعذر التواصل مع البائع فمن الممكن استعادة المبلغ.

إذن يُكتب نص الدعم على أساس هذه المدة (أسبوع) فقط. لا نستخدم عبارة «ستة أشهر» الموروثة من متاجر أخرى، وأي وعد دعم أوسع يحتاج قرارًا واضحًا من المالك.

## حدود المنصات المُعلنة

| المنصة | ما هو موثق داخل المشروع |
|---|---|
| Android | minSdk 24 وtargetSdk 36 في ملف بناء أندرويد |
| iOS | الحد الأدنى iOS 15.0 |
| macOS | الحد الأدنى macOS 15.0 |
| Windows وLinux | بناء قياسي عبر أدوات Flutter مع تنفيذ SQLite عبر sqflite_common_ffi |
| Web | بناء عبر flutter build web، مع ملاحظة أن ميزات المنصة الأصلية محدودة |

هذه الحدود مقروءة من ملفات المشروع. يلزم بناء release حديث لكل منصة قبل الرفع لإثبات أن التطبيق يعمل فعليًا عليها.

## حقوق الملفات المُضمّنة

- **Almarai-Regular.ttf**: رخصة SIL OFL 1.1 مضمونة داخل ملف الخط نفسه، ومسموح إعادة توزيعها. تُرفق مع نص الترخيص، وذكر المصدر هو مستودع الخط على Google Fonts.
- **arial.ttf**: خط من خطوط مايكروسوفت، ورخصته المدمجة تمنع أي استخدام خارج منتجات مايكروسوفت. مستبعد من الحزمة، والشيفرة لا تستخدمه.
- **الرموز الصغيرة وصورة البدء والشعار**: يُفترض أن هذه من إنتاج صاحب المشروع، وتحتاج تأكيدًا صريحًا منه قبل الرفع.
- **التبعيات من pubspec.lock**: مكتبات مفتوحة المصدر برخص MIT وأمثالها، وتُوثق في ملف القفل نفسه.
